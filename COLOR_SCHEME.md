# Professional Color Scheme

## Overview
The Black-Scholes application now uses a consistent, professional color palette across all pages and components.

## Color Palette

### Primary Colors
- **Primary Blue**: `#1565C0` - Main accent color for headers, primary metrics, and UI elements
- **Primary Orange**: `#F57C00` - Secondary accent for volatility and alternative data
- **Success Green**: `#2E7D32` - Positive values, profit, call options
- **Error Red**: `#C62828` - Negative values, loss, put options

### Background Colors
- **Light Background**: `#F8F9FA` - Main background for cards and containers
- **Border Color**: `#E0E0E0` - Subtle borders and grid lines
- **White**: `#FFFFFF` - Primary background

## Component Colors

### Headers
- Gradient: `#1565C0` → `#0D47A1` (Blue gradient)
- Text: Gradient text effect for visual appeal

### Metric Boxes
- Background: `#F8F9FA` → `#E3F2FD` (Light blue gradient)
- Border: `#1565C0` (Blue left border)
- Text: `#1565C0` (Blue values)

### Success/Profit Indicators
- Background: `#C8E6C9` → `#A5D6A7` (Light green gradient)
- Border: `#2E7D32` (Dark green)
- Text: `#1B5E20` (Very dark green)

### Loss/Error Indicators
- Background: `#FFCDD2` → `#EF9A9A` (Light red gradient)
- Border: `#C62828` (Dark red)
- Text: `#B71C1C` (Very dark red)

### Charts
- **Price Chart**: `#1565C0` (Blue line with light blue fill)
- **Volatility Chart**: `#F57C00` (Orange line with light orange fill)
- **P&L Chart**: Dynamic (Green if profit, Red if loss)
- **Grid**: `#E0E0E0` (Light gray)
- **Background**: `#F8F9FA` (Light gray)

## Usage Guidelines

### When to Use Each Color

**Primary Blue (#1565C0)**
- Main headers and titles
- Primary metric values
- Primary action buttons
- Main chart lines
- Primary borders

**Success Green (#2E7D32)**
- Positive P&L values
- Profit indicators
- Call option cards
- Maximum values
- Upward trends

**Error Red (#C62828)**
- Negative P&L values
- Loss indicators
- Put option cards
- Minimum values
- Downward trends

**Primary Orange (#F57C00)**
- Volatility metrics
- Secondary data
- Alternative indicators
- Drawdown values

## Consistency Rules

1. **Headers**: Always use blue gradient
2. **Positive Values**: Always use green
3. **Negative Values**: Always use red
4. **Neutral Values**: Always use blue
5. **Backgrounds**: Always use light gray (#F8F9FA)
6. **Borders**: Always use light gray (#E0E0E0)

## Accessibility

- All colors meet WCAG AA contrast requirements
- Color is not the only indicator (text labels are always present)
- Colorblind-friendly palette
- High contrast between text and background

## Browser Compatibility

All colors use standard hex notation compatible with:
- All modern browsers
- CSS gradients supported in all modern browsers
- No special plugins required

## Future Enhancements

- Dark mode support (inverted color scheme)
- Customizable color themes
- High contrast mode for accessibility
- Color-blind friendly mode
